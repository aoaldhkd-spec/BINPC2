# BINPC2 V6 · V3 통합 기능 대조표

최신 본문·V3 원문·실제 수령한 로고8종을 함께 적용했다. 기존 보고서와 커밋/실패 증거를 대체·삭제하지 않는다.
A=완료 및 격리 자동검증, B=구현했지만 추가 검증 필요, C=아직 미완료, D=오류·외부 승인 등 차단. A도 운영 배포/실기기 완료를 뜻하지 않는다.
최신 숫자·SHA·실패 상세는 [최종 보완 보고서](EVENT_HUB_V6_COMPLETION_2026-10-27.md)와 [보존 자료](reviews/v6-completion-20261027/README.md)를 우선한다. 이전 V3 보고서/validation은 역사 증거로 보존한다. 사용자가 별도 시험사이트 생성을 취소했으므로 외부 주소·새 Render 비용 승인을 기다리지 않는다.
