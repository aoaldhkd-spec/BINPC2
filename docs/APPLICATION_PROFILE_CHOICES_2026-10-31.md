**수정본은 운영 미배포. 현재 기존 주소에서 일반 이용자의 신청 없는 하트나우 사용은 아직 불가하다.** 사용자가 배포를 나중에 하겠다고 했으므로 배포·운영 설정·운영 DB는 변경하지 않았다. 읽기 전용 실제 조회에서 보스 잠금 ON, 미인증, `heartnowPublic` 미활성 상태를 확인했다. 코드가 준비된 상태와 실제 사이트에서 사용 가능한 상태를 구분한다.

## 변경

- 혼자 신청·동반신청의 년생을 **90년대/00년대 → 년생 버튼**으로 통일했다. 기존 프로필의 선택 목록을 재사용하며, 일반 목록 밖의 저장된 년생과 다른 년생 선택도 보존한다. 화면 표시 변경으로 서버 참가자격을 바꾸지 않는다.
- 사는 곳은 **지역 → 도시 버튼**으로 고른다. 부산은 **구/동 중 하나만** 선택한다. 동 검색·목록 밖 직접 입력을 유지한다. 부산 선택 후 도시 목록을 접어 작은 화면에서 세로 길이를 줄였다. 지역 구분 탭을 열었다는 이유로 다른 도시·년생을 자동 확정하거나 서버에 저장하지 않는다.
- 기본 선택을 하지 않은 상태에서는 다음으로 넘어가지 않는다. 기존 필수 동의·다음 버튼의 실제 서버 저장·지연 응답/실패 보호·동반신청 개인별 권한·입금/승인·순번 규칙을 유지한다. 전화번호를 새로 요구하지 않는다.
- 신청 화면의 관리자 설정 톱니는 lucide SVG를 사용하고 20px 크기를 고정했다. 링크 배치 CSS가 랜딩 화면의 CSS에 의존하던 연결을 제거해 신청 화면 안에서 정의했다. 제목 오른쪽 공간도 확보했다. 기존 운영 버전의 입장 후 설정 탭에는 이모지 톱니가 남아 있으며, 이전 개발 커밋의 SVG 교체도 함께 보존한다. 실제 휴대폰에서 보고된 모든 깨짐의 원인을 확인했다고 확대하지 않는다.
- 기존 할로윈 테마·로고·하트·채팅·이벤트 탭·관리자 문의를 보존한다. 신규 외부 사이트·HTML·운영 배포·일반 모집 개방·DB/키 변경은 없다.

## 오늘 사용과 다음 재개 지점

1. **아직 배포 전**이므로 기존 주소에 이번 신청 UI·설정·이벤트 탭 수정이 보인다고 안내하지 않는다. 보스 잠금 전체를 임의로 풀어 일반 하트나우를 여는 방법은 사용하지 않는다.
2. 기존 개발 코드의 `HEARTNOW_PUBLIC_ACCESS=1` 전환은 하트나우의 기존 인증·프로필·하트·채팅 경로만 열고, 신청/시험실/관리 경로의 보스 보호·테스트 ON·`publicAdmissionOpen=false`는 유지한다. 해당 전환은 운영에 적용하지 않았다.
3. 사용자가 배포 재개를 요청하면 최신 Drive 인증·운영 자료 외부 사본의 재다운로드/해시·격리 복원·기존 별도 키 일치부터 이어 확인한다. 현재 최신 사본의 Drive HTTP401은 미해결이며 이전 검증된 외부 백업과 키는 보존했다. 연결을 불필요하게 다시 반복하지 않는다.
4. 그 뒤 이번 최종 코드 버전에 맞는 프런트/서버를 기존 서비스에 함께 반영하고 실제 접근 범위·실행 버전·프로필 복구·하트·채팅·오늘 일반 할로윈 행사/재고 준비를 확인한다. 이전 d917 프런트 ZIP은 이번 신청 UI가 포함되지 않으므로 최신 수정본으로 착각해 배포하지 않는다.
5. Netlify 자동빌드는 사용자 확인대로 ON, Render 자동배포는 OFF를 유지한다. main 병합·설정 변경·실제 모집 오픈을 이번 저장 작업에 포함하지 않는다.
