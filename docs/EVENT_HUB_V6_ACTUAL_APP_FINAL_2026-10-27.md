## 실제 화면 확인과 Cursor 실행

`docs/reviews/v6-actual-app-20261027/README.md`에 실제 캡처·영상·다운로드를 정리했습니다. HTML 시뮬레이터를 실제 앱 프리뷰로 안내하지 않습니다. 이 환경의 내부 localhost는 외부 접속 주소가 아닙니다. 현재 사용자가 설치 없이 볼 수 있는 것은 **실제 앱 캡처와 시연 영상**이며, 직접 클릭 가능한 실제 앱은 준비된 개발 환경이나 Cursor의 격리 실행이 필요합니다. 유료 서비스·공개 프리뷰는 만들지 않았습니다.

Cursor는 같은 GitHub 브랜치 최신 HEAD를 그대로 이어받습니다. 재구현/bundle 복원은 필요 없습니다. `node scripts/event-hub-local.mjs configure`→`check`→별도 api/web→`activate`가 기존 재현 경로입니다. 자세한 실행·테스트 명령은 최신 인계문을 참고하세요. 실제 기기 검사는 별도로 남아 있지만, 환경을 옮기는 것 자체가 기능 완성의 필수 조건은 아닙니다.
