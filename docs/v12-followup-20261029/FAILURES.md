# 실패·원인·수정·재검사

이전 실패를 지우거나 성공 결과로 덮어쓰지 않았다. 원본 로그는 비공개 `.local`에 유지하고 공개본에는 개인정보 없는 요약과 SHA-256만 기록한다.

승인 갱신 수정은 `artifacts/boltnew-app/src/lib/event-hub-client.ts`, 재발방지 검사는 `src/event-hub/event-hub.test.tsx`에 있다. 앱을 승인된 것으로 강제하거나 API 권한·대기시간 검사를 제거하지 않았다. 정상 SSE 연결 중에도 저장/조회와 승인 알림이 겹치는 두 순서를 결정적으로 재현했다.

초기 하트/채팅 부하 도구는 현장 bearer 바인딩 대신 쿠키만 써서 정상 권한 거절을 받았다. 도구를 실제 입장 API가 발급한 bearer로 수정했다. 서버의 인증을 느슨하게 바꾼 것이 아니다. 수정 전 도구 로그도 남겨 두었다.

집중 구간 P95 2초 목표는 아직 미달이며 [15분 성적](soak-150-15min.json)에 그대로 기록한다. 기기푸시·실물폰·운영 배포 미실행을 PASS로 처리하지 않는다.
