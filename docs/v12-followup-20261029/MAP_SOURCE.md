# 전국투어 지역 지도 출처

`artifacts/boltnew-app/public/event-art/korea-tour-map.svg`는 Natural Earth 1:50m 국가 경계의 South Korea(KOR) 형상을 사용한 간단한 지역 안내다.

- 원본: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
- 이용조건: Natural Earth public domain — https://www.naturalearthdata.com/about/terms-of-use/
- 인천·서울 종로/신림·광주·대구 점은 지역의 대략적인 중심이다. 실제 매장 좌표나 이동 경로를 뜻하지 않는다.
- 상세 장소/지도 파일과 별개다. 기존 로고9종을 새로 그리지 않았으며 원본 비율을 유지했다.
- 공개 게시·모집은 하지 않았다. 포스터는 기존 제작 스크립트로 만든 검토 파일이다.
