## Netlify: 확인된 사실과 한 가지 설정

Netlify API 사이트 목록은 401, GitHub hooks는 403 `Resource not accessible by integration`. 환경과 저장소의 지정된 credential 파일에 Netlify 인증값이 없음을 값 노출 없이 확인했다. Branch deploys/Deploy Previews의 실제 값을 읽지 못했으므로 UNKNOWN이다. Render는 사용자가 알려준 main 자동 배포를 유지하고 main을 전혀 건드리지 않았다. 서비스 설정을 임의 변경하지 않았다.

사용자가 해야 할 설정은 **Netlify의 해당 BINPC2 프로젝트에서 `Build status`를 `Stopped builds`로 바꾸기** 한 가지다. 위치: Project configuration → Build & deploy → Continuous deployment → Build settings → Build status. 이 설정은 branch/PR preview를 포함한 새 Git 기반 빌드를 중단하며 현재 배포된 사이트 파일을 삭제하지 않는다. Netlify의 새 production 빌드도 일시 중단되므로 기존 배포를 유지한 상태로 적용한다. 설정이 실제 저장됐다는 증거를 확인하기 전에는 push/PR을 실행하지 않는다. UI의 세부 표기는 계정 버전에 따라 달라질 수 있으나 변경할 값은 `Build status = Stopped builds` 하나다.
