## 최신 사용자 결정
1. 매일 자동으로 새 행사를 시작하지 않는다. 관리자 '회식 시작' 버튼이 행사를 활성화하고 그 행사에 대해서만 23:00 일반하트/24:00 무지개하트/01:00 입장 차단/다음 17:00 초기화 시각을 적용한다.
2. '회식 종료'는 신규 입장만 막고 기존 하트/1:1·단체채팅을 임의로 잠그거나 초기화하지 않는다. 사용자가 직접 선택한 잠금은 유지한다.
3. 초기화가 실행되면 회식 상태는 자동 종료. 다음 시작 전에는 새 행사나 소급 초기화 금지. 이전 행사 기록이 보존되기 전 파괴적 초기화 금지.
4. 관리자 화면에서 이전 행사 날짜별 참가자·하트(일반/무지개)·채팅·시그널·연락처 교환·관리자 작업·통계·오류 기록을 조회하고 검색할 수 있도록 한다. 보관기간·민감정보 접근통제·동의는 별도 확정 필요. 개인정보 원문을 무기한 저장한다고 확정하지 않는다.
5. 시작/종료 시 범일NPC의 모든 종류 하트 사용가능량을 채운다. 이미 전송한 기록을 위조·삭제하지 않고 NPC에 한정된 명시적 잔량 정책을 만든다. 일반 참가자 하트에는 영향 없어야 한다.
6. 테스트 계정→매일 복원되는 범일NPC에 하트 및 1:1 채팅을 실제 전송해 저장·SSE·화면 수신을 각각 검증한다. 테스트 데이터 표시 및 중복방지, 대상 NPC ID/운영 시간/권한 확인 전 실전 쓰기 금지.
7. NPC 자동 체크는 테스트용 내부 설정에 한정하며 개인정보 제3자 동의 또는 운영체제 푸시 권한 자동수락으로 가장하지 않는다.
