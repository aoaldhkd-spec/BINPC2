# 힉스필드에서 한국어로 행사 포스터·영상을 만드는 방법 — CURRENT DRAFT 2026-10-28

공식 시작 화면: https://higgsfield.ai/ko
공식 가이드: https://higgsfield.ai/creator-hub/help-center/getting-started/how-do-i-create-my-first-generation

## A. 정확한 완성 포스터를 그대로 사용할 때 — 크레딧 0

1. 대화에 첨부된 '범일NPC_행사홍보_V7_개별포스터'에서 원하는 PNG를 클릭해 다운로드합니다.
2. PC방 다운로드 폴더의 파일을 열어 날짜·회비·문장이 잘 보이는지 확인합니다.
3. 바로 카카오 공지에 올릴 때는 Higgsfield를 거치지 않아도 됩니다. 프롬프트만 복사한다고 기존 포스터보다 정확해지는 것은 아닙니다.
4. 게시 전 오픈채팅 URL의 행사 적용 범위·개인별 선입금액·취소기준·실물 경품 수량 확인 필요. 공개 게시·자동 모집은 별도 승인 범위입니다.

## B. Higgsfield로 포스터 디자인을 바꾸고 싶을 때

1. Chrome에서 https://higgsfield.ai/ko 에 접속합니다.
2. 기존 Ultra 계정으로 로그인합니다.
3. 상단 '이미지(Image)'를 누르고 '이미지 생성(Create Image)' 화면을 엽니다.
4. 모델(Model)을 열어 **Seedream 5.0 Pro**(한글·인포그래픽) 또는 **Nano Banana Pro**(원본 PNG 편집)를 선택합니다. UI에 없으면 GPT Image 2.5를 대체 선택합니다.
5. 비율(Aspect ratio)을 **9:16**으로 선택합니다. 가능하다면 2K 이상.
6. 기존 페이지 PNG 하나를 사진/참고 이미지(Reference/Upload) 칸에 올립니다. 서로 다른 페이지를 한 번에 하나의 이미지로 합치지 않습니다.
7. 이 문서와 같이 제공된 해당 행사의 **'포스터_한국어지시문_V8'**을 텍스트 입력칸(Prompt)에 붙여넣습니다. 정확한 기존 문구를 따르라고 지시합니다.
8. 생성(Generate) 버튼의 사용 크레딧을 확인하고 필요한 1장만 만듭니다. 사용 크레딧이 예상보다 많으면 실행하지 않습니다.
9. 왼쪽/중앙 결과·자산(Assets)에서 완성된 결과를 열어 원본과 **날짜/가격/상품 수량/한글 띄어쓰기/로고**를 1:1 비교합니다.
10. 틀린 숫자나 한글이 생기면 AI 결과를 바로 게시하지 말고 원래 제공한 정확한 PNG를 사용하세요. 수정/다운로드 후 PNG로 저장해 휴대폰에서도 확인합니다.

## C. Higgsfield로 영상 만들 때

1. 상단 '동영상(Video)' → '동영상 만들기(Create Video)'를 엽니다.
2. 모델(Model)에서 **Seedance 2.5**를 먼저 검토합니다. 1장 사진의 카메라 이동만 필요하면 **Higgsfield DoP**(일부 메뉴에서 Higgsfield Standard)도 선택할 수 있습니다.
3. 영상 기반 이미지(이미지 업로드/Upload image)를 추가합니다. 한글이 많은 포스터를 직접 움직이면 글자가 일그러질 수 있으므로 텍스트 없는 배경 이미지를 우선합니다.
4. 해당 **'영상_한국어지시문_V8'**을 프롬프트(Prompt) 칸에 붙여넣습니다.
5. 세로 **9:16**, 짧은 **3~5초**로 시험합니다(해당 모델에서 지원하는 길이로 선택). 720p 시험 후 필요한 경우에만 최종 품질을 올립니다.
6. 생성 버튼에 현재 표시된 실제 크레딧을 확인하고 생성합니다. 실패 시 무작정 반복하지 말고 프롬프트에서 한 부분만 변경합니다.
7. 생성 결과는 자산(Assets)에 표시됩니다. 재생하여 인물·손·화면 전환·카메라 움직임을 검수합니다.
8. 날짜·회비·모집 조건이 보이는 포스터 원본을 **편집 단계에서 별도 정지화면/자막 레이어**로 합성합니다. 영상 생성 AI에 글자 자체를 새로 쓰게 하지 마세요.
9. 최종 영상은 H.264 MP4, 9:16, 가급적 720×1280/24fps, 낮은 평균 비트레이트로 저장합니다.
10. PC방 다운로드 폴더에서 최종 MP4 오른쪽 클릭 → **속성 → 크기**를 확인합니다. **5,000,000바이트 미만**이어야 '5MB 이내'로 처리합니다. 더 크면 비트레이트를 낮춰 다시 출력하고 확인해야 합니다.

## D. 어떤 모델이 맞는가

- **긴 한글 표·조건이 많은 정적인 포스터:** Seedream 5.0 Pro의 한국어 글꼴·고밀도 문서 지원을 첫 후보로 추천.
- **기존 포스터를 유지하며 네온 배경/배치만 수정:** Nano Banana Pro.
- **광고형 일러스트·타이포그래피:** GPT Image 2.5.
- **사람이 있는 시네마틱 배경 사진:** Soul 2.0. 텍스트는 별도 합성.
- **포스터 한 장에서 카메라 이동:** Higgsfield DoP.
- **멀티샷 행사 홍보영상:** Seedance 2.5. 크레딧 아끼려면 Draft 등 제공되는 시험 모드를 먼저 확인.

일부 메뉴는 앱 업데이트에 따라 명칭/배치가 바뀔 수 있습니다. 공식 기본 흐름은 Image/Video → 모델 → 프롬프트·참고 → 설정 → Generate → Assets입니다.
