🎬 전국투어 힉스필드 홍보영상 한국어 지시문

[제작 목표]
25~30초 홍보를 목표로 4~5초 단위 한국 야간 도시 전환 장면을 제작합니다.

[프롬프트 — 복사해 사용]
한국의 밤거리 네 장면을 부드럽게 연결합니다. 인천의 항구 도시 분위기 → 종로의 도심 불빛 → 광주의 따뜻한 야경 → 신림의 활기 있는 도시 분위기. 실제 매장이라고 주장할 수 있는 간판이나 인위적으로 만든 업소 로고는 생성하지 않습니다. 카메라는 느리게 이동하고 전환은 부드럽습니다. 젊은 성인 친구들이 자연스럽게 만나 대화하는 친근하고 절제된 분위기. 과도한 클럽·파티 인파, 글자·날짜·가격·QR은 생성하지 않습니다.
최종 편집 때 기존 전국투어 포스터 PNG의 도시·날짜·회차표·선입금+1/N·금토 1차 추억의 뽑기 정보를 정확한 글자로 순서대로 보여주세요.

[영상 제작 공통 제약] 9:16 세로. 기존 포스터의 정확한 한국어·숫자·로고가 왜곡되거나 움직여 번지면 안 됨.
별도 생성하는 영상 장면에는 글자·간판·가격·QR을 쓰지 말고, 완성 포스터 PNG를 자막/화면 정지 장면으로 편집할 때만 올리세요.
영상의 0.5~1초 시작·종료에 브랜드명과 일정 정보가 읽히도록 안정적으로 화면 유지. 급격한 줌·빠른 회전·도형 일그러짐 금지.
마지막 홍보 영상은 반드시 5,000,000바이트 미만을 실측해야 함(권장 목표 4.5MB 이하). Higgsfield Generate 버튼은 5MB 파일 보장이 아님.
[방법] Higgsfield '동영상(Video)' → '동영상 만들기(Create Video)' → 모델 'Seedance 2.5' 또는 단일 포스터의 움직임만 필요하면 'Higgsfield DoP'.
기존 이미지(배경 또는 포스터)를 '이미지 업로드'칸에 넣고 아래 움직임 지시문을 붙여넣기. 종횡비 9:16, 가능하면 짧은 4~5초부터 생성 후 결과 검토.
영상에 글자를 정확히 보여줄 때는 원본 포스터 PNG를 별도 편집으로 영상에 겹치거나 전환/정지화면으로 삽입하세요.
