## 직접 시험하는 순서

1. 기존 주소 새로고침 → 기존 운영자 로그인.
2. **술번개 신청 → 할로윈 신청·이어하기 → 날짜 → 신청하기**. 본인 기본정보·동의·회비를 확인합니다. 실제 송금은 하지 않습니다.
3. 오른쪽 톱니바퀴 **관리자 → 술번개 → 신청·입금**에서 해당 시험 신청만 가상 승인합니다.
4. **신청대기방**으로 돌아와 프로필 작성 → **술번개 입장하기**를 확인합니다.
5. 시간·가상3등·뽑기 시험은 **관리자 → 술번개 → 행사 설정·기록·관리 도구 → 선착순 시험실**을 사용합니다. 진행 중 시험 기록을 유지하려면 초기화를 누르지 않습니다.

갤럭시·아이폰에서는 같은 브라우저로 프로필·고유번호·하트·대화를 확인한 뒤 화면 잠금/해제, 은행·카카오톡 이동 후 복귀, 새로고침, 네트워크 끊김/복구를 비교합니다. 프로필·신청이 처음부터로 돌아가는지와 오류 시 기존 정보가 남는지 확인합니다. 실제 휴대폰은 사용자 확인 전 UNKNOWN이며 자동 Chromium 검사와 구분합니다.

## 동반신청 후속 정책 · 현재 작업

최신 사용자 확정: **대표자와 친구가 함께 신청하는 순간 사람별 순번·회비를 확정. 합산 입금 가능. 관리자가 사람별로 각각 승인.** 앞서 선택했던 각자 입금 답변은 후속 정정으로 대체합니다. 자동 송금·환불·일괄 승인이나 초대코드 입력은 추가하지 않습니다.

이번에 배포한 UI에서는 친구 정보 작성·저장까지만 가능하며 최종 확정 기능은 후속 개발 중입니다. 본인/친구 권한과 동의를 분리하고, 완성·검사한 코드로 추가 반영할 때 실행 버전과 보존 상태를 다시 확인합니다. 진행 중 사용자 시험을 임의 초기화하지 않습니다.
