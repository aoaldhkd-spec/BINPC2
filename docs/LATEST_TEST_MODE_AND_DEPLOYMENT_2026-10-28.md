## 배포 후 운영자가 확인할 순서

1. 기존 관리자에서 `술번개`를 열고 **관리자 테스트 모드 ON**을 확인한다.
2. `행사 설정·기록·관리 도구` → `선착순 시험실`에서 금요일·토요일·전국투어 시나리오를 선택한다.
3. 가상 3등, 입금 신고·승인, 프로필 작성·현장 입장, 뽑기를 확인한다. 화면의 **테스트 결과** 표시를 확인한다.
4. 다시 열어 이어지는지 확인하고 합성 하트·대화도 시험한다. 실제 참가자 정보를 입력하지 않는다.
5. `테스트 데이터 초기화` 확인란과 버튼으로 시험 기록을 지운다. 다른 탭에 남은 기록이 다시 저장되지 않는지 확인한다.
6. 일반 브라우저에서는 계속 신청 차단 안내가 보여야 한다. 실제 오픈은 정책·운영 확인 후 별도로 결정한다.

이 순서는 최신 코드 배포 후 사용할 안내다. 현재 운영 사이트가 최신 버전이라고 안내하지 않는다. 실제 Galaxy·iPhone의 잠금/해제, 은행·카카오톡 복귀, 알림·소리·잠금화면 수신은 여전히 실물 확인이 필요하다.
