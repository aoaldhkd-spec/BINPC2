## 자동배포 위험

현재 Netlify는 `main`만 자동 빌드하며 `stop_builds=false`, Render도 `main` 자동배포가 켜져 있다. 향후 main 변경이 수동으로 고정한 테스트 버전을 덮을 위험이 있다. 개발 브랜치에만 저장하고 PR/main 변경을 하지 않는다. 방지 설정은 Netlify **Stopped builds**와 기존 Render 서비스의 **Auto-Deploy Off**지만, 사용자가 별도 승인하기 전 설정을 변경하지 않는다. 이 검토를 자동배포 중지 완료로 보고하지 않는다.

## 하트나우 단독 사용 문의

기존 하트·채팅 기능과 신청 기록은 별도로 보존된다. 그러나 현재는 사이트 전체 보스 잠금, 프런트 접근 경계, 공용 입장/테스트모드 판정, 신규 프로필의 행사신청 검사까지 연결돼 있어 일반 이용자의 즉시 단독 사용은 불가능하다. event_hub만 OFF하거나 버튼만 켜서 해결했다고 보고하지 않는다. 하트나우만 공개하려면 기존 본인인증·실시간·현장 입장 판정을 술번개 접수/시험행사에서 분리하고 시험 프로필 노출 방지를 검증해야 한다. 사용 범위 확인 중이며 일반 공개/설정 변경은 실행하지 않았다.
