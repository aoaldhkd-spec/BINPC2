# 전체 할로윈 테마를 끄거나 나중에 분리하는 방법

이 문서는 V12의 시각 계층과 업무 기능을 구분합니다. 이번 작업에서는 기존 장식·원본·선택 아바타를 삭제하지 않았습니다.

## 현재 OFF 방법

기존 관리자 모듈 설정의 **전체 할로윈 테마**를 끕니다. 서버의 `module_flags.seasonal_landing` 값과 `SeasonalSkin`의 변경 이벤트가 연결됩니다. 화면 전체를 새로 고치거나 입력·세션·채팅을 초기화하지 않습니다. 기존 다크/라이트 선택도 덮어쓰지 않습니다. 전체 테마 기본 만료는 **2026-11-01 17:00 KST**이며 PC 시간을 변경하지 않습니다.

행사별 테마 토글/만료는 `event-hub-modules.ts`의 별도 정책입니다. 할로윈 금요일 회차는 10월31일17시, 토요일 회차는11월1일17시에 만료합니다. 술자리 종료·신규입장 마감01시와 다릅니다. 테마를 꺼도 신청·입금·승인·대기방·문의·당첨·지급 원장은 남습니다.

## 연결 지점과 자산

| 위치 | 역할 |
|---|---|
| `artifacts/boltnew-app/src/themes/SeasonalSkin.tsx` | 전체 화면의 `html[data-seasonal-skin=halloween]` 적용/제거, 설정 재조회·수명 정리 |
| `artifacts/boltnew-app/src/themes/halloween.css` | 선택자 안의 색·장식·짧은 모션. 데이터 저장/입금 조건 없음 |
| `artifacts/boltnew-app/src/lib/landing-season.ts` | 한국시간 전체 테마 기간, 수동 OFF 우선 |
| `artifacts/boltnew-app/src/event-hub/EventPresentation.tsx` | 행사별 표지/로고. 비공개 장소 권한과 공개 로고 분리 |
| `artifacts/boltnew-app/public/halloween*` 등 기존 정적 테마 자산 | 장식 원본을 유지. 장식 실패 시 본문과 버튼 자체는 기본 CSS로 표시 |
| `public/avatars/av361.webp`~`av390.webp`와 기존 아바타 | 사용자 선택값 호환 자산. 테마 OFF 때 삭제하지 않음 |

CSS는 기본 번들에 포함되며 OFF 시 선택자가 비활성화됩니다. 따라서 ‘할로윈 코드가 0바이트 다운로드된다’고 주장하지 않습니다. 선택한 아바타는 OFF여도 정상적으로 내려받아 표시해야 합니다.

## 나중에 영구 제거할 때

1. 전체 테마 모듈을 OFF하고 실제 화면의 입력·복구·하트·채팅을 확인합니다.
2. `SeasonalSkin` 래퍼와 전용 CSS import만 제거하는 별도 변경을 준비합니다. 날짜·접수·입금·승인·개인정보·카드 정책 파일은 제거 대상이 아닙니다.
3. 참조 검색 후 장식 자산만 후보로 분류합니다. 사용자가 선택한 아바타, 원본 로고, 업로드, 당첨 원장은 보존합니다.
4. 기본 테마와 다크/라이트, 행사별 테마, 이전 선택 아바타를 다시 검사한 뒤 반영합니다.

## 이번 증거와 한계

`SeasonalSkin.test.tsx`, `landing-season.test.ts`, 행사 모듈 단위/DB 검사로 OFF·만료·업무 분리를 검사했습니다. 실제 앱 브라우저 검사에서 새 아바타 저장→재접속→테마 OFF 후 선택 이미지/행사 카드 링크가 유지됨을 확인했습니다. 모든 메뉴의 장식 파일 실패 조합과 실제 휴대폰 소프트키보드는 별도 미검증 항목입니다. 자세한 실행 범위는 `docs/v12-validation-20261029/`를 확인합니다.
