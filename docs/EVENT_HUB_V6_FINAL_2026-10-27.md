## 발견한 오류와 수정

1. 불확실한 저장을 재시도할 때 mutation 전에 기존 nonce의 영수증을 조회한다. 초기 세션 생성 실패는 같은 고엔트로피 코드로 복구한다.
2. 브라우저 저장소가 차단돼도 서버에서 성공한 복구를 무효 처리하지 않고, 서로 다른 로컬/세션 저장소 정리를 독립적으로 시도한다. 회원 로그인도 공통 복구코드 저장을 쓴다.
3. 문의의 내부 태그·사유를 참가자에게 보내지 않는다. 처리 완료·재개·미처리 건수를 구현했다.
4. 파기 시험에서 복구 해시를 빈 값으로 만들면 2명째 unique 충돌이 날 수 있어, 발급하지 않는 고유 tombstone으로 바꿨다. 개인정보를 포함할 수 있는 검토 사유·광고 동의도 시험 파기 시 최소화한다.
5. 개발 관리자 bridge의 운영 API 기본값/운영 자격증명 파일 의존을 없앴다. LOCAL_API=1+명시된 loopback HTTP 주소+개발 비밀번호+로컬 접속만 허용한다.
6. 테스트 DB URL의 host 쿼리 옵션이 주소 검사를 우회하지 못하게 제한했다. 기존 리셋 DB 검사에도 파괴적 쿼리 전 안전 검사를 추가했다.
7. 허브 화면 effect 의존성과 타이머 경계를 보완하고 기존 권한 검사와 초기화 코드를 보존했다.
