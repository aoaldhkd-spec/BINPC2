## 자격·사진·설명서

1991~2007년생은 기본 범위, 1990년생 이전은 사전 문의/수동 검토다. 미성년 출생년도는 기존 서버 성인 검사로 거절한다. 성별·성정체성 자동 판별·사진 분석·IP/지역만의 동일인 차단은 만들지 않았다. 관리자 준비상태만 확정 인원/최소5명을 보여주고 일반 신청자에게 전체 인원을 공개하지 않는다.

검토 사진은 별도 동의·전송 전 메모리 미리보기·2MB/서명 검사·암호화 원본·소유자/관리자 열람·검토 결과·원본 삭제 확인을 구현했다. 별도 썸네일·서버 임시본을 만들지 않고 수신 영수증에 사진 원문을 복사하지 않는다. 격리 파기 시험에서도 사진 잔존을 처리한다. **운영 사진 업로드는 보관/백업 정책 확정 전 차단**한다. 삭제 UI는 서버 원본과 백업 미확인을 구분하며 백업까지 삭제됐다고 주장하지 않는다.

`TutorialModal.tsx`, `AppOverlays.tsx`와 첫 입장 안내를 조사했다. 기존 TutorialModal에 신청용 내용을 주입하고 기존 현장 안내는 유지했다. 첫 신청과 `? 신청 방법` 재열기·모바일 뒤로가기/Escape를 지원한다. 개발 StrictMode에서 자동 안내가 즉시 닫히던 오류를 보완하고 회귀 검사를 추가했다. 별도 큰 설명서/독립 HTML/홍보 포스터·홍보 영상은 만들지 않았다.

## 검증·보존

최종 숫자·원격CI·SHA·다운로드는 아래 최종 결과/동봉 validation.json을 기준으로 한다. 기존 테스트를 삭제하거나 느슨하게 만들지 않았다. 실제 DB는 고정 loopback fixture만 사용한다. 브라우저는 localhost만 허용하고 운영 API/DB로 보내지 않는다.

환경이 한 차례 unavailable→재접속되었다. 소스와 기존 Docker 볼륨/키는 남아 있었고 변경29개 파일을 별도 tar/patch로 백업했다. 중단된 기존 컨테이너를 재시작했으며 DB/키를 새로 생성하거나 원래 개발 DB를 삭제하지 않았다. 사라진/tmp 로그와 진행 중 프로세스는 새 환경에서 재검증했다. 이후 로그는 `.local/campaign-resume/`에 보존한다.
