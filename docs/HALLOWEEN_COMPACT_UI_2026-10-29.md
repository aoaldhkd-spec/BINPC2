# 범일NPC 술번개 — 화면 정리와 할로윈 강화

**기존 주소 반영 완료:** <https://binpc2.netlify.app/>를 새로고침하면 새 화면을 확인할 수 있다. 관리자 진입은 오른쪽 위 톱니바퀴다. 보스 로그인·일반 이용자 차단은 그대로 유지한다.

기준: 개발 브랜치 `830a6adbbb81c08810926509295ba434e6e2237a`에서 이어서 수정했다. API·DB·기존 데이터·운영 키는 수정하지 않았다. 이 문서의 검사와 과거 V6 결과는 별개다.

## 요청별 반영

| 요청 | 반영 및 확인 |
|---|---|
| 상단 테스트 안내 3줄 제거 | 공통 보스 배너/링크 제거. 보스 인증·일반 방문자 차단·SSE 보호는 유지. 관리자 진입은 우측 톱니바퀴, 로그아웃은 기존 관리자 화면. |
| 웹 표시 이름 변경 | 메인·신청·관리자·알림 문구를 `범일NPC 술번개`로 변경. 기존 주소·저장키·행사 ID·공지 원문·동의 버전은 유지. |
| 버튼 색상 정돈 | 신청은 주황, 대기방은 짙은 보라, 입장은 크림색. 세 버튼과 프로필 복구 버튼은 기존 기능에 연결. |
| 입장 아래 보스 설명 제거 | 제거. 일반 참가자에게 필요한 시작 전·오류·개인정보·실제 송금 방지 안내는 유지. |
| 다른 화면의 불필요한 설명 | 로그인·신청의 중복 설명과 참가자에게 보이는 시험행사 이름 접미사 정리. 관리자 이력·서버 값은 유지. |
| 간단한 화면의 스크롤 축소 | 메인 320×568 / 390×700 / 768×1024 / 1440×900에서 버튼과 복구 버튼이 한 화면 안에 표시됨. 신청 기본입력 단계도 390×700에서 다음 버튼까지 표시됨. 긴 공지·프로필·목록·글자 확대·키보드에는 자연 스크롤 유지. |
| 할로윈 강화 | 달·성·촛불·호박 배경과 금색 테두리 추가. 메인은 밝게, 입력 화면은 가독성을 위해 어둡게 표시. 기존 테마 ON/OFF·만료와 분리 구조 유지. |

친구 입력 카드와 부가 설정은 작성 단계에서 숨기되 컴포넌트를 유지해 미저장 입력이 사라지지 않도록 했다. 새 배경은 이번 UI 요청을 위한 생성 장식이며 사용자 제공 로고·포스터 원본을 수정하거나 합치지 않았다.

- 첫 원격 CI `40874476306`의 실제 브라우저 검사에서 19개 통과·3개 실패를 확인했다. 신청 생성 후 재사용 로그인 설정까지 숨겨진 부분을 다시 표시하고, 비보스 방문자의 접수 차단 안내를 복구했다. 할로윈 색상 검사는 요청한 새 색상으로 갱신했으며 ON/OFF 검사는 유지했다. [실패 원인·수정 기록](halloween-compact-ui-20261029/initial-ci-failures.json)을 보존한다. 이 실패를 이전 성공 기록으로 덮지 않는다.
- 실물 갤럭시·아이폰, 실제 백그라운드 푸시: UNKNOWN. 자동검사는 Chromium 화면 크기 변경이며 실기기 해결 완료를 의미하지 않는다.
- 수정 후 실패 항목을 분리 재검사하고, 최종 코드 `517c3efeb2d0ea01526084d98d4cb784554ff86a`의 [CI 40876794794](https://github.com/aoaldhkd-spec/BINPC2/actions/runs/40876794794)에서 **27/27 단계 성공**을 확인했다. 브라우저·100세션·누적 150명 실제 HTTP/PostgreSQL 회귀검사가 포함된다. 이 성공은 기존의 모든 성능·실기기 미확인 항목이 해결됐다는 뜻은 아니다.
