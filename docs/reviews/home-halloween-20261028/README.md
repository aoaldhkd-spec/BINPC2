## 용량·다운로드·저장 범위

최종 정적 빌드 전체는 8,236,416바이트이며 직전 8,232,472바이트보다 3,944바이트 증가했다. 새 이미지 파일은 추가하지 않았다. 자료를 지워 용량이 줄었다고 보고하지 않는다. 실기기/운영망 속도는 미측정이다.

현재 소스·화면·보고서·Cursor 인계는 [다운로드 ZIP](BINPC2-current-Cursor.zip), 체크섬은 [SHA256SUMS](SHA256SUMS.txt)로 보존한다. 소스 기준 커밋은 `b991dd297e2930500b082894070a8dfbdaffd3f5`. `.local`, 비밀값, DB 덤프, Git 이력, 종전 ZIP 중복은 포함하지 않는다. 기존 전체 비공개 Git bundle에 이번 변경의 증분 bundle을 추가하고 복구 의존 커밋을 검증했다. 이 자료들은 운영 DB·업로드·암호화키 백업을 대신하지 않는다.
