# 전체 할로윈 꾸미기 · 실제 페이지 사진

2026-10-28. 기존 전체 테마에 거미줄·매달린 거미·박쥐, 주황 조명, 어두운 파티 배경을 더했다. 이 꾸미기는 기존 전체 테마 OFF와 함께 사라진다. 원본 로고와 사진, 기존 기능을 삭제하지 않았다.

실제 React·Express·격리 PostgreSQL 앱에서 **112장**을 촬영했다. 운영 화면·실제 참가자 사진이나 실기기 검증 결과가 아니다. 개별 상태·긴 화면의 아래 부분을 별도 사진으로 포함했다. 신청 저장·실패 복구·입금 승인·프로필 완성·입장·카드 복구를 수행한 실제 브라우저 검사 1개도 통과했다.

사진은 22장 공개 화면, 13장 신청 흐름, 23장 참여자 화면, 54장 관리자 화면이다. 비밀번호·API키를 표시하지 않았다. 노출된 참가자 이름·고유번호·전화번호는 이 외부 비공개 격리 DB의 합성 검증 자료다. 관리자 비밀번호 입력은 빈 상태다.

일반 프로필 작성은 여섯 단계를 촬영하고 마지막 등록은 누르지 않았다. 관리자 설정 페이지는 조회·탭 선택만 사용했다. 신청 검사는 격리 DB에만 합성 기록을 만들었다. 참고 사진 사이트 Unsplash·Pexels·Dribbble은 이번 환경에서 CONNECT 403으로 열리지 않아, 실제로 열람했다고 하지 않는다. 기존 사용자가 제공한 포스터 분위기와 기존 앱 장식을 바탕으로 보완했다.

이 112장 묶음은 테마 촬영 체크포인트다. 이어진 최신 신청 안내·복장 인정 최소 수정의 화면은 `latest/` 보충 사진으로 별도 보존하며 기존 사진을 수정된 후속 화면이라고 바꿔 설명하지 않는다. 운영 배포 승인과 모집·정책 승인은 구분한다. 운영 사이트 배포가 확인된 자료가 아니다.
