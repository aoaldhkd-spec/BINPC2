# 로고별 사용 기준 — 실제 파일 복구 확인

상태: 자산 확보·파일 검증 완료 / 앱 연결·GitHub 변경·운영 배포 미실행.

대상은 7개 매장 + 고래 감사용 1개로 총 8종이다. 대구 BLACK은 제외했다.

## 2. 원본 보존과 추출

8개 원본 파일은 `03_원본보존`에 바이트 그대로 복사했다. 원본은 불변이며 SHA256으로 검증했다.
레드홀·체크인·스피드·고래는 제공 화면/디자인 안의 로고 영역만 잘라 별도 PNG로 넣었다. 이것은 별도 벡터 원본이 아니라 원본 픽셀을 그대로 추출한 파일이다.
나머지 페이크·자크·온탑·M가라오케는 기존 파일을 그대로 앱용 폴더에도 복사했다.
로고 자체에 새 글자/도형/효과를 생성하지 않았고, 색 변경·AI 재생성·업스케일하지 않았다.

## 3. 중요한 구분

자크: 최신 금색 지퍼·흰 원형·Jack membership 파일을 선택했다. 이전 빨간 JACK 네온 시안은 포함하지 않았다.
M가라오케: 이전 대화의 제작 시안을 복구했다. 공식 원본으로 표시하지 않는다.
체크인: 제공 도안에 포함된 COMING SOON은 그대로 보존했다. 현재 영업 상태에 관한 별도 주장으로 사용하지 않는다.
고래: 감사용이다. 전국투어 행사장이나 공동주최로 자동 지정하지 않는다.
온탑: 현재 대화에서 받은 원본과 같은 파일이다.

## 4. 앱 연결 검사

원본 비율을 유지하고 로고 전체가 보이게 한다. 기존 앱 테마/여백/다크모드와 조화시키되 로고 내부를 임의 재디자인하지 않는다.
행사별 장소와 차수는 로고 확보와 별개다. 운영자가 지정한 장소 연결만 사용한다.
승인자에게만 보여야 할 실제 장소를 로고로 우회 노출하지 않는다.
파일 다운로드 성공·앱 경로 연결·브라우저 실제 표시·운영 배포는 각자 다른 검증 단계로 기록한다.

## 5. 과거 설명 정정

이전 자료의 “다른 로고 미수령” 및 “온탑만 실제 파일 확보”는 이번 복구 이전 상태 설명이었다. 이번 ZIP에는 8종 실제 파일이 들어 있다.
원래 대화 전체를 내보낸 것이 아니라, 사용자 지정 대화의 로고 자료를 Library 파일로 찾아 실제 열람·복사한 결과다.
