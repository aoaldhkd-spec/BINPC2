## 지금 체험하는 방법

`BINPC2-V6-demo.html`을 다운로드해 Chrome에서 연다. 설치나 로그인 없이 참가자와 관리자 버튼으로 전환한다. 관리자 전환은 인증 보안 검증이 아닌 가상 역할 전환이다. 파일에 실제 정보는 입력하지 않는다.

- 시작 화면: 가상 3등, 50,000원에서 10,000원 할인한 40,000원. 4등 버튼은 50,000원이다.
- 신청 처음부터: `시험 데이터만 초기화` → 가상 닉네임 `가상체험`, 1995년, 부산, 연락처 `01000000000`, 입금자 `가상입금자` → 필수 동의 → 회비 확인 → 확정 → 입금 신고.
- 승인: 관리자 화면 → 입금 승인 → 가상 대조 확인 → 참가 확정/현장 확인 → 참가자로 전환해 장소 공개 확인.
- 프로필: 대기방에서 미리 설정/이어쓰기. 미완성은 입장할 수 없다. 필수 설정과 승인·현장 확인·가상 회식 시작이 필요하다.
- 빠른 체험: 가상 진행 상태에서 `프로필 미완료`, `현장 입장` 등을 선택한다. 이 선택은 기존 가상 신청을 교체하는 시작 지점 선택이다.
- 카드: `현장 입장` 상태 → 카드 3장 → 4번째 추가 시도는 거절. 관리자의 현장 지급 버튼으로 하리보/경품 기록을 확인한다.
- 관리자 문의: 가상 문의 수집 동의와 내용을 입력해 전송하고 관리자 화면에서 답장한다.
- 장애: 모의 조건을 펼쳐 저장 전 실패/응답 유실/인터넷 끊김/저장 지연을 선택한다. 재접속·저장 상태 복원과 새로고침을 확인한다.
- 가상 행사 설정: 관리자 화면의 행사·혜택·카드 설정에서 날짜·시간·장소·공지·회비·할인·카드 ON/OFF를 바꾼다. 확정된 신청 금액은 자동 변경하지 않는다.

## 접속 방식과 한계

이 환경에는 외부 프리뷰 URL 발급·포트 공개 도구가 없다. 따라서 공개 HTTPS 주소와 비밀번호 보호 테스트 서버는 만들지 않았다. 추가 서비스나 유료 리소스도 만들지 않았다. 이 파일은 다운로드형 독립 체험판이며 실제 DB 검증용 프리뷰가 아니다.

휴대폰은 파일을 옮겨 HTML 실행을 지원하는 브라우저에서 열 수 있으나 실제 Android/iOS 파일 열기와 PC방 보안 정책은 UNKNOWN이다. 관리형 Chromium의 file:// 접근은 ERR_BLOCKED_BY_ADMINISTRATOR로 차단되어, 같은 산출물을 격리 정적 HTTP에서 검증했다. 이 제한을 우회하거나 보안 설정을 해제하지 않았다. 파일 열기가 차단되는 PC방이라면, 다음 단계로 외부 프리뷰 지원 환경 또는 별도 정적 테스트 호스팅이 필요하다. 사용자에게 공개 배포 승인 없이 임의 호스팅하지 않는다.

탭의 sessionStorage만 사용한다. 새로고침 복원과 탭 종료·다른 기기 복구는 다르다. 후자는 이 파일에서 지원하지 않으며 실제 서버 구현의 기능이다. 실제 비밀번호, 송금, 서버 세션, 푸시 구독/발송을 만들지 않는다.

## 이번에 확인한 보완 사항

관리자 내부 메모가 참가자의 신청 이력에 포함될 수 있어 공유 projection에서 제외했다. 동의 화면에서 재사용을 선택했다가 해제했을 때 회원 레코드가 남는 경로를 수정했다. 광고 수신거부 서명은 정확한 64자리 hex와 토큰 형식을 검사한다. Node의 hex 디코딩이 비hex 접미부를 잘라내므로, 잘못된 서명을 거부하는 DB 검사가 이 오류를 찾아 수정했다. 보호 검사는 삭제하지 않았다.

운영 개인정보 정책이 미확정이므로 production 환경의 새 모집 활성화와 새 신청은 명시적으로 차단된다. 기존 신청자의 승인 기록 읽기/복구를 다시 신청으로 바꾸지 않는다. 이 차단을 해제하려면 향후 확정 정책 반영과 검증이 필요하다.

## 안전 및 GitHub 보존

독립 빌드는 `.env` 로드를 끄고, 일반 App 부트스트랩/서비스워커/운영 프록시를 사용하지 않는다. 단일 HTML에 JS/CSS를 포함하고 CSP `connect-src 'none'`, `frame-src 'none'`, `worker-src 'none'`, `form-action 'none'`으로 외부 API·프레임·발송을 차단한다. 번들 URL 문자열은 React 진단/표준 SVG 네임스페이스만 있으며 운영 API 주소가 없다. 브라우저 검증의 외부 요청 0건, 오류 0건을 확인한다.

실제 DB 검사는 새 로컬 `binpc2_hub_test_resume`에 한정한다. 운영 DB·실제 참가자·실제 계좌는 사용하지 않았다. 생성한 환경 비밀값은 코드/보고서/다운로드에서 제외한다. 다운로드는 체험판·가상 스크린샷·검증 요약·기존/신규 보고서만 포함하며 토큰/세션 저장 파일은 포함하지 않는다.

원격 push는 보류다. Netlify/Render 설정이 저장소에 있으나 실제 브랜치 자동 배포 설정은 UNKNOWN이고, 서비스 API 읽기는 네트워크 CONNECT 403으로 차단되었다. 외부 프리뷰도 이 문제를 우회해 만들지 않았다. main 병합·push, 운영 배포·모집 공개·실제 발송을 실행하지 않았다.
