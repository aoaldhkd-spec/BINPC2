# 행사 장식 이미지

`halloween-lounge.webp`는 2026-10-28 사용자 UI 참고 방향에 맞춰 생성한 장식용 이미지다. 실제 행사장이나 매장 사진이 아니다. 사람·상호·매장 로고를 포함하지 않는다.

- 노출: 공개 공지 표지가 없는 **활성 할로윈 행사** 카드와 상세 화면에만 사용.
- 해제: 기존 행사별 `useEventTheme` 및 다음 날 17:00 KST 만료를 따른다.
- 공개 공지 업로드가 있으면 그 공지를 우선 사용한다. 비공개 지도·포스터·매장 로고를 대체 표지로 노출하지 않는다.
- 원본 PNG는 작업환경 `/workspace/generated_images/exec-b8268f98-97b4-4b0e-90ec-744248c83e83.png`에 보존. 앱용 WebP는 동일 이미지 형식 변환, 169,690 bytes.
- 제공된 전국투어 로고 8종은 수정하지 않았다.
